Difference between HTTP and Websocket:
HTTP is a protocol for delievering web pages on the browser. HTTP is a stateless transfer protocol. It means that server treats each request as entirely indepenent .

Web socket connects clients and servers. It differs from HTTP in a way that it allows client to communicate as long as they want on a single linke. Unlike HTTP where every request is brand new, web socket allows to make multiple requests in a single established connection.
